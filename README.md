# MLOps Lab 1 — Iris Model Service on Kubernetes

Based on the class slides, pages 49–52. Includes scikit-learn training, MLflow tracking, FastAPI model serving, Docker, Kubernetes Deployment/Service and CPU HPA (1–5 replicas, 50% target).

## Prerequisites
Python 3.12, Docker Desktop (running), kubectl, kind, hey, and a working Kubernetes metrics-server. Commands below use PowerShell.

## 1. Train and track
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python train.py
mlflow ui --port 5000
```
Open http://localhost:5000, select experiment `iris`, and capture the run details screenshot as `screenshots/mlflow-run.png`. `model.pkl` is generated by training.

## 2. Build and deploy
Open another PowerShell terminal in this directory:
```powershell
kind create cluster --name mlops
docker build -t iris-api:v1 .
kind load docker-image iris-api:v1 --name mlops
kubectl apply -f k8s/deployment.yaml
kubectl rollout status deployment/iris-api
kubectl get pods
kubectl port-forward svc/iris-api 8080:80
```
In a third PowerShell terminal:
```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/predict -ContentType 'application/json' -Body '{"instances": [[5.1,3.5,1.4,0.2]]}'
```
Expected prediction: 0.

## 3. Enable HPA
HPA requires metrics-server. In a local kind environment, install a metrics-server manifest compatible with your Kubernetes version and configure its kubelet certificate settings if necessary. Confirm `kubectl top pods` reports CPU usage before proceeding. Do not disable kubelet TLS verification in production.

```powershell
kubectl apply -f k8s/hpa.yaml
kubectl get hpa iris-api -w
```
Keep the port-forward running. In another terminal, generate load:
```powershell
hey -z 120s -c 50 -m POST -T application/json -d '{"instances": [[5.1,3.5,1.4,0.2]]}' http://localhost:8080/predict
```
In another terminal:
```powershell
kubectl get pods -w
kubectl top pods
```
Observe HPA CPU metrics and replica changes (scaling is workload- and cluster-dependent). If replicas remain at 1, check `kubectl describe hpa iris-api`, metrics-server, CPU usage and load duration. Capture genuine scaling evidence as `screenshots/hpa-scaling.png`.
